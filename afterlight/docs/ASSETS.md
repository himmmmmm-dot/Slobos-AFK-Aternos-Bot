# Asset and licence manifest

Checked 2026-11-10. Milestone 1 ships **no asset files**. Everything the player sees and hears is generated by this repository's own code at runtime.

## Game content

| Asset | How it is made | Source | Rights |
|---|---|---|---|
| Level geometry | Boxes and wedges built from level data | `src/game/levels/graybox.ts`, `src/client/render/levelMesh.ts` | Original |
| Panel texture | Drawn on a canvas | `src/client/render/levelMesh.ts` | Original |
| Security unit model | Primitives assembled in code | `src/client/render/enemyView.ts` | Original |
| Pistol and arm | Primitives assembled in code | `src/client/render/viewmodel.ts` | Original |
| Effects (muzzle flash, tracers, sparks, scorch marks, bolts) | Canvas textures and pooled primitives | `src/client/render/effects.ts`, `viewmodel.ts` | Original |
| Sound effects, ambience, music | Synthesised with Web Audio oscillators and noise | `src/client/audio/audio.ts` | Original |
| Story, names, dialogue | Written for this game | `src/game/levels/graybox.ts`, `src/client/ui/ui.ts` | Original |
| Fonts | The player's system fonts | CSS font stack | Nothing is distributed |
| Voice acting | None. Dialogue is text with subtitles | — | — |

No AI-generated images, audio or third-party art packs are included.

## Rules for later milestones

Any model, texture, sound or font added later gets a row here with its author, source URL and licence before it is merged. Paid assets and anything that needs attribution are flagged in the milestone report first, so they never become a surprise at submission.
